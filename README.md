# Online Marketplace UI

A static **online marketplace user interface** developed using **Next.js 13** as a project submission during my time at **PIAIC (Presidential Initiative for Artificial Intelligence and Computing)**.

This project focuses primarily on the frontend design and user interface of an e-commerce marketplace rather than the complete marketplace functionality.

## Live Demo

**[Dine Mart — Online Marketplace UI](https://mydinemart.vercel.app/)**

## About

This project is a frontend implementation of an online marketplace interface designed to present products through a modern e-commerce layout.

The interface includes sections such as:

* Hero and featured product sections
* Product listings
* Product categories
* Promotional sections
* Discount offers
* Product cards
* Newsletter section
* Responsive navigation and layout
* Responsive styling for different screen sizes

The project was created as a **PIAIC project submission** to demonstrate my ability to build a modern web interface using Next.js and related frontend technologies.

## Tech Stack

* **Next.js 13**
* **React**
* **JavaScript / TypeScript**
* **Tailwind CSS**
* **Vercel**

## Key Concepts

Through this project, I practiced:

* Building interfaces with Next.js
* Developing reusable React components
* Creating responsive layouts
* Designing product and e-commerce interfaces
* Working with Tailwind CSS
* Structuring a frontend application
* Creating reusable UI sections and components
* Deploying a Next.js application using Vercel

## Project Context

This project was developed during my time at **PIAIC** as a project submission.

It represents the **static UI/frontend portion** of an online marketplace. The focus was on implementing the visual interface and overall user experience rather than developing the complete backend, database, authentication, or commerce functionality.

A separate, more complete version of the online marketplace was also developed by me and is maintained in another repository:

**[Online Marketplace — Dine Mart](https://github.com/SheikhXAdil/Online-Marketplace-Nextjs13)**

That project extends beyond the static UI and represents my larger implementation of the marketplace concept.
